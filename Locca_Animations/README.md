# Locca Animations

- `promo-film/` – all Locca animation projects: business film, fox-route (HyperFrames, `hf/`), lemo-opuscar films (`opuscar/`), audio, review frames and rendered outputs (`out/`).
- `sunra/` – Sunra fox idle loops.
- `app-stickers/` – sticker and illustration assets from the customer app (fox UI, splash, Rive onboarding, map pins, icons).
- `lemo-opuscar/` – copy of the lemo-opuscar film library (MIT, LemoLab, https://github.com/lemomo-ai/lemo-opuscar). Not included: `node_modules`, `.venv` and the sample packs in `core/audio/instruments/` (1.1 GB, re-download with the library's own tools).

Run `npm install` inside `promo-film/` (and each opuscar project) before rendering.
